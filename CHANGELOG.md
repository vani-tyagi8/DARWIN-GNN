# Changelog

## 0.2.0

- Added resumable, MD5-verified downloads for the public processed Devign, ReVeal,
  and Big-Vul graph archives from Zenodo record 7057996.
- Added deterministic train-to-validation assignment while preserving source tests.
- Added indexed JSONL storage and lazy loading for multi-gigabyte datasets.
- Corrected the model to match the reference Devign input zero-padding and dual
  Conv1d/max-pooling/multiplicative graph readout.
- Added a verified Windows CUDA setup helper and expanded dataset documentation.
- Expanded the automated suite to eight tests.
